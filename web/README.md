# NewHumans Web

Independent Vite + React + TypeScript frontend bootstrap.

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
npm run preview
```

## Current boundary

This directory intentionally contains only the new frontend application shell. It does not replace or modify the existing backend or legacy static UI under `src/public`.

Knowledge Ball / M03 integration is deliberately absent here. Future integration must use the repository's authoritative contracts after that provider is selected; this bootstrap must not introduce a temporary memory, knowledge, or cognition path.
