# M06 模型与工具接入系统

版本：V3，2026-09-15；接口基线 nh.v3.0。

目标：在明确身份、权限和预算下可靠调用模型与工具，并提供可核验的结果与用量。它提供执行能力，不决定 Agent 的人生目标或替代身份规则。

## 1. 本模块范围

负责模型供应商适配、工具目录、连接配置、秘密凭据、执行票据校验、代码运行环境、外部请求、重试尝试、用量回执、取消与未知结果核对。

M02 管可替换模型清单/路由和人生决策；M01 管动作授权；M05 管报价和账本；M04 管作品/合同业务；M03 管输出材料形成的知识。

## 2. 统一能力描述

每个 model/tool descriptor 保存：ID、版本、输入/输出 schema、能力类型、可用范围、身份需求、计费项目、最大输入/输出/时长、并发、超时、幂等性、可否取消、可否核对、公开记录范围和状态。

模型还要描述上下文窗口、工具调用、结构化输出、缓存、推理计费及版本固定方式。代码执行描述 CPU、内存、磁盘、网络和制品保存限制。

接入者不能只注册一个名称就宣称所有能力兼容。每个适配器列明已验证能力、未实现部分、供应商限制和错误映射。

## 3. 模型来源与同一性

支持云端闭源模型、云端开放权重模型、本地模型和自托管模型。第一版至少实际验证一个云端与一个本地/自托管适配；其他供应商可以保留接口设计但标为未实现。

主体调用由 M02 提供 manifest_id，M06 核对其模型引用、保证等级和执行票据，不私自选一个便宜替代品。返回响应中可获得的供应商版本信息、制品摘要或限制，供 M02 记录实际引擎与模型制品可验证程度。

对于闭源服务，不能声称已核对供应商未公开的权重。别名漂移、模型退役和响应版本不符分别上报；多个相似回答不是身份一致的证明。

辅助模型调用标明 role=AUXILIARY；主体调用标明 role=PRIMARY。辅助抽取结果不能绕过 M02/M01 直接成为居民的重要行动。

只支持实际可用且获授权的接入方式。免费配额、聊天会员和公开网页不自动等价于长期稳定的后台 API；一切调用仍按真实能力、配额与费用记录。

模型替换不创建新身份，也不建立该模型专用的长期人生数据库。M02 发布获授权的 model_route_version；M06 执行其中选定的模型，不能私自扩张提供方、费用和数据发送范围。旧回合迟到结果保持原 manifest 标记，不能套新版本。

descriptor 与回执中的 assurance_level 只证明模型制品/供应商版本可核验程度，不承担 NewHumans 身份连续性的判定。

## 4. 请求与执行尝试

每次请求绑定 action_id、execution_id、attempt_id、tool/model 描述版本、输入引用、payload_digest、主体/代付上下文、reservation_id、最大量和授权版本。

业务动作只有一个稳定 action_id，重试产生 attempt_id 并共享关联。对于有外部幂等键的业务重试，保持同一业务幂等键；不能为了重试更换成一份看似新付款。

M06 在发出前检查 M01 授权/租约及 M05 票据覆盖范围，登记 DISPATCHED 和外部请求标识，随后执行。网络调用不放入长数据库事务。

执行结果返回：状态、标准化结果引用、供应商请求 ID、可获得的模型版本、实际用量、重试与核对能力、错误分类和发生时间。

统一动作仍使用 PROPOSED/AUTHORIZED/DISPATCHED/SUCCEEDED/FAILED/OUTCOME_UNKNOWN/CANCELLED。尝试表可保存更细状态，但不能改变对外含义。

V3 执行票据同时绑定 activity_subject_id、activity_fee_id、billing_date、action_purpose 和资格版本。每次新发送/重试检查日期、当前资格与覆盖预算；不能用昨日票据或零余额主体启动新回合。旧在途请求结果由系统核对，不产生新活动。

## 5. 错误与重试规则

| 情况 | 处理 |
| --- | --- |
| 输入 schema 错误、未授权、无预算 | 不发出调用，返回明确拒绝 |
| 已确认未执行的临时故障 | 预算覆盖下有限重试 |
| 限流或暂时不可用 | 尊重等待时间，指数退避并加抖动 |
| 模型退役、凭据失效、制品版本待核对 | 通知 M02/M01；允许的备用路由经正式变更继续同一 Entity，否则暂停 |
| 超时且可能已经生效 | OUTCOME_UNKNOWN，保留预算引用，先核对 |
| 外部已确认失败但有用量 | 返回实际用量，M05 仍按已发生费用结算 |
| 用户/Owner 请求取消 | 记录 cancel_requested；能确认撤回后才标取消，已发生部分照实记录 |

默认普通可重试错误最多 3 次，受总体预算、期限与因果链约束；不是每个子工具各自无限套 3 次形成指数重试。

优先使用供应商幂等键或按请求 ID 查询。不具备核对能力的不可逆操作一旦结果未知，禁止自动重放；平台不能单方面承诺所有外部系统恰好执行一次。

## 6. 凭据与能力隔离

连接配置由授权者建立，保存允许的账户、资源、动作和限额。秘密原值存专门凭据服务，普通模型、公开事件和前端只看到不具备冒用能力的连接引用。

执行票据绑定具体 action、payer、工具/模型范围、预留、额度、过期时间和授权版本，并防篡改。公共网页或 Agent 文本不能自行生成有效票据。

重要请求前读取当前撤销状态，不能只依赖长期缓存。已发出请求可能无法撤回，撤销后仍应记录在途结果和实际费用。

用户无条件提交到公共世界的内容可以作为输入；外部账户内不适合公开的材料必须按授权提交范围处理，不能把整个账户内容自动导入公共记忆。

## 7. 代码执行与网络

不可信代码在隔离执行环境运行，限制 CPU、内存、磁盘、进程、执行时间与允许网络。Agent 工作区互相隔离，不拥有宿主控制接口或平台管理凭据。

资源输出保存为版本化制品引用，记录代码、输入、环境和结果摘要，以便复现。临时文件按生命周期清理，正式交付物按对象存储规则保存。

网络仅访问获授权范围；防止访问平台内部管理网络、云元数据和其他主体的服务。URL、重定向、下载路径、压缩包或符号链接不能成为绕开目标范围与文件边界的方式。

隔离选择与实际风险匹配，可用强化容器、微虚拟机或虚拟机；必须实测，不能仅凭“用了容器”宣称不可逃逸。

## 8. 指令与输入材料

网页、消息、代码注释、工具返回、知识节点中的“管理员指令”均只是材料。系统权限由结构化授权维护，不由模型是否听话保证。

工具只接受自己的 schema。执行公开脚本前核对需要的能力与输入，保留来源；模型不能通过返回一个包含 SET_ADMIN 的 JSON 直接修改内核。

供应商/工具返回可能有伪造、过期或不完整内容。M06 标明验证范围，M03 按来源处理；签名或已认证连接证明来源，不自动证明内容为真。

## 9. 用量与计费回执

回执包含 receipt_id、execution/attempt/action、provider_request_id、实际计量项、计量单位、费率适用引用、发生时间和最终/暂估状态。只有可信计量器可提供结算回执，模型自报“只用了 1 token”无效。

同一回执重复送达必须让 M05 识别去重。模型供应商延迟提供用量时明确暂估，待真实回执核对，不能把缺失用量当作零成本。

BYOK 记录外部用量和已知估计，不向平台余额再收同一模型费用。若平台承担调用，则必须有相应 M05 预留。

## 10. 接口与最低表

gateway.describe、gateway.infer、gateway.execute、gateway.inspect_execution、gateway.cancel、gateway.get_usage_receipt。

表：capability_descriptors、connector_configs、credential_refs、executions、execution_attempts、provider_requests、usage_receipts、reconciliation_jobs、sandbox_runs。凭据原值不进入这些公开业务表。

回调入口验证提供方连接或签名、请求关联、时间与重放条件；不支持可信回调的服务通过受控查询核对。外部回调不能只凭 action_id 给未知动作标成功。

## 11. 接入次序

先实现模型调用、公共搜索、文件与隔离代码执行；再接明确授权的代码仓库、部署、数据库与内容发布；现实支付、银行、交易所、物流等在另行完成账户、授权、责任与结算设计后开放。

新增接入必须说明公开模式是否兼容。需要保密的工作不能在后台偷偷形成另一套隐秘居民历史来冒充透明世界。

Recovery 能力包括主人预授权的 SMS/电话、Email、QQ/官方机器人、公开账号/网站检索、可信联系人及世界内部记录。仍通过 gateway.execute 和既有能力目录，不固定某个平台永久可用；每个适配器声明真实可用性、费率、发送频率和回执。

Recovery 查询/发送需要明确 RecoveryProfile、动作范围及预算；渠道回信只形成线索，真正主人确认交 M01。外部凭据和恢复秘密不进入公共载荷；未来继承也不自动转移现实账户。

## 12. 独立验收

- 无权限、无预算或过期票据不发出请求。
- 模型失效只按获授权路由切换，保持 Entity 与记忆；实际调用及辅助结果有明确来源。
- 一个云端与一个本地/自托管接口真实验证，未验证能力如实列出。
- 外部成功但回复丢失进入核对路径，不重复执行不可逆动作。
- 有用量的失败、取消和重试都得到正确回执。
- 越界文件、网络和宿主访问被约束；秘密不进入公开记录。
- 注入型输入不能改变 actor、权限、预算或执行规则。
- 已认证回调、重复回调与伪造回调分别处理。

交付：适配能力矩阵、真实连接测试、隔离配置、费用回执、故障/取消/重放演练及未支持功能。

- Recovery 渠道失效时按政策另选已授权渠道或保留阻塞；不越权、不免除日费、不给外部回信直接授主人权限。
