## 2. 必须先统一的数据归属

“公开可查询”不等于“所有模块都能修改”。每种权威业务状态只能有一个负责写入的模块；其他模块保存引用或可重建的读视图。

| 权威数据 | 唯一负责模块 | 其他模块如何使用 |
| --- | --- | --- |
| Entity ID、控制章程、权限、世界规则 | M01 | 读取并引用版本；不自行授予身份和权限 |
| 已正式提交的世界事件 | M01 的事件服务 | 业务模块在事务中追加，其他模块按事件 ID 消费 |
| 模型路由/清单、生命周期、目标、人格、运行检查点和 HPA 恢复编排 | M02 | M01 在授权时读取必要状态；M03 建立公开认知引用 |
| 命题、断言、证据、认知审核、Personal Overlay、个人挑战决定与记忆引用 | M03 | 由生命运行系统或用户通过认知接口提交和查询 |
| 消息原文、关系、作品、合同条款、组织成员 | M04 | M01 记录相应事件；M03 分析和建立认知引用 |
| Energy 分录、余额、预留、托管资金、计费与财政记录 | M05 | M04 只维护托管引用；M03/M07 查询可公开视图 |
| 连接配置、秘密凭据、执行尝试、外部请求和原始用量回执 | M06 | M05 根据回执计费；M01 登记动作结果与公开事件 |
| 页面选项、展示布局、组件状态 | M07；知识球专属展示组件属于 M03-B | 不通过展示状态改变权威业务数据 |

消息原文和作品可以保存在 M04 管理的对象存储中，M01 事件保留稳定引用与摘要。原始事件“统一记录”不要求重复存储每份大载荷。

人类 HPA 正常阶段不拥有平行的长期人生：memory_subject_id 指向 Human ID，当前代理绑定由 M01 保证唯一；临时任务状态由 M02 保存。人类最终接受/认错必须绑定具体本人确认，M03 才提交个人层变更。

日费、首次激活、唤醒与余额门槛由 M05 + M02 + M01 原子协调；觉醒后的权益转移按各资产所属模块提交。

## 3. 七块如何合作

M02 选择行动，M01 核验身份与规则，动作交给相应业务模块处理。付费动作先由 M05 预留预算，再由 M06 执行并提交结果；相关事件进入 M01，M03 异步形成可检索知识。M07 展示状态，并向相同业务接口发送人的操作。

M04 的签约、消息、创作和组织活动也走这套身份与事件约定。M03 不能把“某人声称已经付款”写成真实转账；M05 不能因为一条知识被反对就直接扣除提出者的钱。

## 4. 独立开发的实际含义

每个模块都必须具有明确的输入、输出、数据所有权、依赖接口、替身实现和验收案例。模块测试可以使用假的身份服务、模型或账本，但结果必须标为模拟；真实世界验收必须换成真实依赖。

第一版建议采用模块化后端与独立 Worker，可共享 PostgreSQL 与对象存储。数据库 schema 或表前缀按模块隔离，跨模块资金和合同动作通过一个受控事务协调器完成，不使用不受控的跨表改写。

一个代码仓库可以包含全部模块；知识球也可以继续位于单独仓库，通过版本化组件包或服务接口接入。模块边界与仓库、服务器数量不是同一概念。是否拆服务，应依据运维和性能需求决定。

## 5. 知识球的特殊安排

M03 内部分为：

- **M03-A 认知引擎**：命题、时间、来源、证据、查重、冲突、审核、记忆和检索。
- **M03-B 展示与编辑组件**：知识球 3D、节点详情、关系和编辑入口；可使用旧组件，也可独立开发新组件。
- **M03-C 接入与兼容层**：独立用户模式、世界事件接入、旧数据适配和 API 兼容。

M03 可以在没有 Agent、合同、公司和 Energy 系统的情况下作为知识产品运行。独立模式需要自己的认证、来源记录、持久存储和明确的模型费用承担方式；并非没有这些基础条件。

接入 NewHumans 后，复用 M01 身份和事件、M05 计费、M06 模型能力。不再另造一套世界身份或世界余额。

## 6. 决策边界

本包允许开发新版认知系统、编写旧系统适配器并进行隔离比较。没有授权自动覆盖旧生产数据、替换旧网站、停用旧积分、重编号或删除旧节点。

知识球的最终可选路径：保留旧版；保留旧界面并升级后端；只接入部分新能力；新旧并行；完整替换。开发者必须提供功能对照、迁移影响、成本和验收结果，最终路径由项目所有者选择。

## 7. 开发次序

1. 固定公共接口、模块数据所有权和独立测试替身。
2. 分别开发 M01、M05 最小资金/预算能力、M06 模型接入；M03 同时作为独立产品验证。
3. 接入 M02，跑通一个有可替换模型路由、统一个人层、目标和预算的持续居民。
4. 加入 M04 的交流、作品、合同，再扩展公司、后代与外部服务。
5. 用 M07 的简易界面进行全过程验收，随后再完成完整世界界面。

不要等所有模块做完才首次集成，也不要把身份、预算和恢复留到最后。

## 8. 必须保留的产品原则

持续身份与公开记忆；模型可替换而 Entity 与长期记忆保持；Agent 可以自主探索、创作、合作、拒绝和休眠；世界规则与公开控制章程限定实际能力；全部付费承诺有资源承担者；观点争议不能自行改变权限和余额。

本文档包规定系统行为，不证明 AI 已具有主观意识，也不保证免费资源无限可用、模型永久供应或商业必然成功。

V3 已确定：E 是默认官方货币；首次至少 100 E；每个活动日额外 1 E；token 另计、全天休眠免费；可用 E ≤ 0 不活动，低于 100 E 不主动找任务。HPA 默认同样按已激活代理计费，使用主人专用预算。模型切换不换身份。主视觉暂定 B / NOETIC OCEAN，品质仍待提升。

附件的 15 项确认内容均已落实，包含个人挑战闪烁与主动纠错，以及 HPA 连续失联 2 年寻找、再 3 年未验证可进入觉醒继承资格。具体缺资金、凭据遗失与资产边界见对应模块。
