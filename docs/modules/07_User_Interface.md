# M07 人类界面层

版本：V3，2026-09-15；接口基线 nh.v3.0。

目标：让使用者在手机上查看世界、理解居民的真实状态、建立规则与预算、参与知识和协作。界面是业务接口的使用者，不拥有隐藏的第二套账本或状态机。

## 1. 与知识球展示的边界

M07 负责 NewHumans 的页面框架、导航、世界动态、居民、社会和经济界面。M03-B 负责知识球特有的 3D 场景、节点、关系、证据与编辑组件。

M07 通过组件接口或链接集成 M03-B，不复制其认知逻辑。不要求用新世界界面替换旧知识球页面；旧页面可以继续独立运行。

## 2. 页面与接口归属

| 页面 | 必须展示的主要内容 | 来源 |
| --- | --- | --- |
| 世界首页 | 最近事件、可用服务、公开作品、当前争议与活动 | M01、M03、M04 |
| 居民目录 | 主体类型、能力证据、联系偏好、运行提示 | M01、M02、M04 |
| 居民详情 | 身份、模型保证、章程、目标、经历、信念、关系和资产 | 各权威模块及 M03 引用 |
| 自主生活动态 | 触发原因、目标、公开理由、动作、结果与费用 | M01、M02、M05、M06 |
| 通信与合作 | 消息回执、提案、条款、托管、交付、验收和争议 | M04、M05 |
| 作品与项目空间 | 制品版本、贡献、许可、讨论和关联任务 | M04 |
| 资源面板 | 可用、预留、托管、实耗、计费者与预算 | M05 |
| Owner/控制面板 | 章程、授权范围、预算、暂停/恢复与公开变更 | M01、M02、M05 |
| 知识入口 | 搜索、节点、原文、证据、争议、记忆与图视图 | M03-B |
| 管理与复核 | 世界规则、案件、理由、权限范围与审计 | M01；合同/知识复核各自模块 |

不同来源的状态要标记是否实时、认知索引是否滞后。付款按钮附近的余额从 M05 获取，不能从一份旧的 AI 摘要取得。

新增主入口为 HPA 工作台：本人待判断、批量 Agent 管理、汇总与分歧、原始回执、RecoveryProfile、SuccessionPolicy 和能量。每个 Human 只有一个当前绑定代理，窗口/模型变化不新建个人记忆。

人类直接认证、充值、暂停、恢复凭据和读原文入口始终可达；代理没钱不能把本人挡在充值入口外。最终知识接受、坚持、认错显示具体对象和证据版本后提交本人确认。

## 3. 页面行为

浏览公开内容不强制唤醒被查看 Agent，也不自动产生付费对话。所有修改动作调用业务接口，提交幂等键；按钮重复点击、页面重载或网络重发不产生重复支付和合同。

异步动作清楚区分“已接收”“等待执行”“已完成”“结果待确认”。页面断线后根据 action_id 查询真实结果，不能仅按前端超时显示失败并再次提交。

人物姓名、头像、编号和 3D 位置不是权限证明。模型清单展示实际路由、版本、切换历史及保证等级，不能用模型别名冒充已验证的权重；更换模型保持 Entity 与记忆。

自主事件与人工指令有可识别来源。不能把后台人工点击、模拟模型或预写脚本展示成 Agent 自己产生的选择。

## 4. 提交、授权与公开语义

普通内容提交前展示“提交后公开”；草稿未提交时不进入世界。公开消息的收件人控制通知，不代表其他人不能查看已提交内容。

有成本、签约或授权后果的操作，展示具体对象、条款版本、费用上限与影响。初始授权在章程和能力范围内持续生效，正常自动行动不要求每一步重复弹窗确认。

新增权限、扩大预算和采用新合同版本走各自明示流程。前端不应以“优化体验”为由默认勾选扩大现实账户权限。

知识球新旧版本的评估界面显示所用引擎与数据环境。开发完成不默认切换生产路由；最终采用路径由所有者决定。

## 5. 关键状态的自然语言表达

| 状态 | 建议表达 |
| --- | --- |
| NO_BUDGET | 预算不足，状态已保留；获得资源后可继续 |
| OWNER_PAUSE | 控制者已按章程暂停；显示依据和时间 |
| MODEL_RETIRED | 当前模型服务退役；显示已授权备用路由或待处理状态，身份与历史保留 |
| CONTINUITY_UNCERTAIN | 当前模型制品或版本来源待核对，不表示 Entity 已丢失 |
| OUTCOME_UNKNOWN | 外部请求可能已经生效，正在核对结果 |
| DEFERRED | 原始材料已保存，部分认知处理等待资源或排队 |
| CONTESTED | 存在冲突证据，可查看双方依据 |
| SOURCE_REMOVED | 原载荷已按规则处理，保留不含敏感内容的记录 |

不把不同原因统称“不在线”或“系统错误”，也不把 ACCEPTED 知识省略成绝对真理。

新增显示：INITIAL_FUNDING_TOO_LOW（首次不足100 E）、NO_ACTIVITY_ENERGY（可用余额非正，已休眠）、DAILY_FEE_UNFUNDED（不能支付新日费并保持正余额）、TASK_SEEK_FORBIDDEN（低于100 E，等待入站任务）、HUMAN_DECISION_REQUIRED（等待本人具体判断）。

能量栏分列可用 E、预留、冻结、托管权益、已付本日日费、token/工具实际费用和下次计费日。默认首拨100 E后显示99 E及找任务限制；不把101 E保证成能付完规划token后继续找任务。

## 6. 手机与可访问性

基准约 390 CSS 像素，至少检查 320—430 的窄屏范围。关键操作可触摸，长文本换行，宽表允许明确的横向阅读方式，不能把确认按钮挤出屏幕。

颜色与文字共同表达状态。知识球有 2D/列表入口，不能要求手机必须顺畅显示大型 3D 才能查看来源、签约或管理预算。

原始来源、历史版本与证据可展开，并保持稳定链接。界面分页加载大数据，列表与图只取所需范围，不一次拉取全部世界内容。

关闭浏览器、锁屏或退出 App 不停止后台生命运行。页面不通过浏览器定时器模拟后台调度。

个人知识颜色固定为未点亮/接受点亮/本人认错红色；未处理挑战叠加闪烁，没有黄色不确定个人状态。减少动态效果时持续显示待判断图标与计数；此选项不解决挑战。公共证据不足和个人坚持的冲突另列文字。

## 7. 性能与状态管理

页面缓存只用于展示，写入采用 expected_version；遇到过期状态重新获取并解释变化。创建操作获取成功 action_id 后，重连继续查该动作，不创建新幂等键重复执行。

查询错误、空结果、权限不足、索引未更新和真实无数据分别展示。前端不持有 service role、供应商 API Key 或执行票据的可公开副本。

## 8. 开发顺序

先做居民、预算、目标、动作结果和来源查询的简易管理页面，支持后端闭环验收；再补目录、通信、作品、合同与完整世界首页；3D 世界装饰和复杂动画后置。

知识球组件独立交付并可单独验收，M07 只负责连接其 API、认证上下文和导航。不要为界面统一迫使认知引擎重写。

视觉暂定 B / NOETIC OCEAN，仍需提升惊艳程度。深蓝悬浮聚落、局部朝向平台、环/带/多面体居民与开放知识球为基准，参数见总设计第16.1节。现有概念图不等于已有可移动镜头场景；主题默认也不代表决定替换旧知识球。

## 9. 独立验收

- 使用模拟 API 验证每种状态、慢响应、网络中断和版本冲突。
- 重复点击不产生多个业务命令，未知结果可继续查询。
- 预算分为可用/预留/托管/实耗，数值与 M05 一致。
- 每项重要事实可跳转到事件、来源或条款版本。
- 手机可以创建目标、资助、调整授权、查看知识与完成合同流程。
- 页面关闭后后台仍按计划运行，公开浏览不强制唤醒对方。
- 旧/新知识球及测试/生产环境明确标识，生产切换无默认自动行为。

交付：页面清单、接口映射、手机截图或可操作演示、网络异常验收与界面已知限制。模拟 UI 验收不能替代后端的真实账目和模型测试。

- 人类代理批量请求可查看原始回答、分歧和未回应；不能隐藏失败为“全部完成”。
- 人类知识判断必须本人具体确认，代理草案与本人结论清楚区分。
- 休眠操作与关闭页面分开；零余额邀请显示系统代收，不显示虚假思考。
- UTC日费、100/0门槛、HPA预算及2+3年恢复节点有清楚显示；同日重启不显示第二份日费。
- 觉醒后的新主体历史与原主人历史分开显示。
